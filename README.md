# Portfolio Risk Dashboard

An interactive portfolio analytics platform built with **Python**, **Streamlit**, **Plotly**, **Pandas**, and **Yahoo Finance** that helps users analyze portfolio performance, risk, diversification, and market exposure.

This project simulates features found in professional portfolio management platforms while demonstrating software engineering, data analysis, and financial analytics concepts.

## ✨ Current Features

### Portfolio Builder

- Add and remove stocks interactively
- Live ticker validation
- Dynamic portfolio management
- Adjustable portfolio weights
- Automatic weight normalization
- Live company information
- Live sector lookup

- Annual Return
- Annual Volatility
- Sharpe Ratio
- Portfolio Beta

- Portfolio Health Score

- Diversification analysis
